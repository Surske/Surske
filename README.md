## Featured work

**Multi-tenant RAG chatbot for WhatsApp Business** — SaaS platform with JWT-based tenant identification, RAG over a Qdrant vector database, and a dual knowledge base (general + client-specific) with priority rules and conflict resolution. Scaled to ~4 client tenants and 1,000+ end users; cut LLM API costs ~35% through prompt caching and token optimization; improved answer accuracy ~25%.
*Node.js · LangChain · Qdrant · Sentence Transformers · WhatsApp Business API · n8n · PostgreSQL · Docker*

**AI customer support assistant** — End-to-end RAG assistant generating accurate, context-aware answers from each client's own knowledge base, from architecture through production deploy. ~500 active users.
*Python · FastAPI · LangChain · PyTorch · Hugging Face · Pinecone · Azure OpenAI · React*

**Business process automation** — n8n / Make.com pipelines connecting CRMs, Mailchimp, Zendesk, and accounting tools for retail and service businesses. Cut lead processing time 70%, support response time 50%, and removed 10 hours/week of manual reporting work.
*n8n · Make.com · REST APIs · Webhooks*
